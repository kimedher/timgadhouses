# Houses of Roman Timgad

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21116238.svg)](https://doi.org/10.5281/zenodo.21116238)

Source repository for [timgadhouses.org](https://timgadhouses.org), an open digital humanities project on the houses of Roman Timgad (Thamugadi) in modern Algeria.

Roman domestic architecture has too often been read through the lens of Pompeii, as if one Italian template could explain a thousand provincial lives. Timgad's houses were built and rebuilt by veterans, workshop owners, and local Numidians, and they tell a different story. This site publishes the data, plans, and arguments behind that reading, in the open, as part of my ongoing dissertation research.

## Tech

Static site built with Jekyll and hosted on GitHub Pages. Custom layouts and a single SCSS stylesheet, no theme.
